# Frostfuscator 1.3.3

Frostfuscator 1.3.3 improves plugin and Kotlin compatibility while keeping graphing, decompilation, and event workloads reliable throughout long desktop sessions.

## Added

- Added dedicated classloader isolation for every runtime plugin, allowing plugins to bundle compatible dependency versions without colliding with Frostfuscator or other plugins.
- Added a configurable graph-cache capacity through the `frost.graph.cache.maxEntries` system property.
- Added a public event-listener exception handler so plugin hosts can route failures into their own logging and diagnostics experience.
- Added Kotlin metadata rewriting so renamed Kotlin classes, functions, properties, signatures, and referenced types continue to work with `kotlin-reflect`.
- Added ProGuard, Tiny v2, and YAML mapping exports in both the CLI and desktop interface for easier crash symbolication and remapping-tool integration.
- Added Java 11 Constant-Dynamic indirection for method handles and field var handles, with independent controls for constants, calls, and fields.
- Added eight accessible desktop themes: Arctic Dusk, Deep Ocean, Mulberry, Ember, Pine, Cobalt, Studio Light, and Sage Light.

## Improved

- Improved graph memory stability with access-aware least-recently-used eviction and automatic cleanup of memory-reclaimed graph results.
- Improved desktop shutdown reliability by cancelling active decompilations, stopping background workers, and clearing viewer caches during normal or abrupt application termination.
- Improved concurrent plugin startup with lock-free, priority-ordered event-handler snapshots that avoid registration lock contention.
- Improved strong and maximum protection profiles with configurable MethodHandle and VarHandle reference indirection.

## Fixed

- Fixed plugin failures caused by conflicting ASM, SnakeYAML, and other bundled dependency versions.
- Fixed Kotlin reflection and inline-function compatibility by preserving `kotlin.Metadata` during debug cleanup unless its dedicated removal option is explicitly enabled.
- Fixed invalid local-variable metadata when a variable name was not available during rename collection.
- Fixed plugin listener failures bypassing Frostfuscator diagnostics and the GUI console.
- Fixed unbounded graph caching that could exhaust memory while analyzing very large applications.
- Fixed background decompiler tasks surviving unexpected GUI shutdown paths.
