# Product

## Register

product

## Platform

desktop

## Users

Frostfuscator is used by Java developers and release engineers who need to protect a JAR without becoming bytecode-obfuscation specialists. Experienced users need complete control over every transformer, while beginners need analysis, explanations, recommendations, and safe defaults that make a successful first build likely.

## Product Purpose

The desktop application turns a Java archive and its dependencies into a validated, protected release. Success means the application understands the selected JAR, recommends compatible protection settings, preserves existing configuration compatibility, exposes advanced controls without overwhelming the main workflow, and makes validation and build results easy to act on.

## Positioning

Frostfuscator combines deep Java protection controls with project-aware guidance, so strong protection does not require guesswork.

## Brand Personality

Calm, precise, and capable. The interface should feel as refined and responsive as Raycast while remaining original, low-glare, and focused on sustained technical work.

## Anti-references

Avoid crowded transformer-card walls, top-heavy navigation, literal snowflake or frost branding, bright cyan action blocks, harsh black-and-white contrast, nested bordered panels, unreliable native dropdowns and spinners, decorative animation, and screens that expose every advanced setting at once.

## Design Principles

- Explain before asking: detect project facts and propose safe values before requiring manual input.
- Progressive disclosure: keep the common path calm while preserving complete advanced control.
- Confidence through feedback: validation, build progress, problems, and quick fixes stay visible and specific.
- Smoothness serves orientation: motion communicates navigation, state changes, and progress without delaying work.
- Compatibility is a feature: existing configuration files and engine behavior remain trustworthy.

## Accessibility & Inclusion

Provide readable low-glare themes, a dedicated High Contrast theme, keyboard-complete controls, visible focus states, configurable font scale and density, reduced-motion support, descriptive validation messages, and layouts that remain usable at the minimum window size.
